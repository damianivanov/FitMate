# AI Actions — Proposal Tools, Confirmation Flow, Frontend Cards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The AI coach can *propose* creating an exercise, a workout, or a workout template — nothing is persisted until the user explicitly confirms the proposal card, at which point the payload is revalidated from scratch and executed through the real domain services, exactly once.

**Architecture:** A new `AiAction` entity records every proposal as `PendingConfirmation` with an untrusted `PayloadJson`; three `IAiToolHandler` proposal tools (`propose_exercise`, `propose_workout`, `propose_workout_template`) create actions but never domain entities. `AiActionService` owns the confirm/reject lifecycle with a portable `int Version` concurrency token guarding against double-confirm, dispatching to per-type `IAiActionExecutor` implementations that revalidate and then call `IExerciseService` / `IWorkoutService` / `IWorkoutTemplateService`. The frontend renders human-readable proposal cards in the AI Coach chat with Confirm/Reject buttons hitting `api/ai/actions`.

**Tech Stack:** .NET 9, EF Core + Npgsql (Sqlite in tests), System.Text.Json (`JsonSerializerDefaults.Web`), xUnit, React + TypeScript + Tailwind, Reinforced.Typings type export.

## Global Constraints

- Follow repo conventions (roadmap D4): services take `(request, long userId)` and **no CancellationToken** — the only exceptions here are `IAiActionExecutor.ExecuteAsync` and `IAiToolHandler.ExecuteAsync`, whose CancellationToken parameters are fixed by the roadmap Shared Contracts. Controllers extend `BaseApiController` and use `this.ReturnJson(...)` / `this.ReturnJsonError(...)`; DTOs in `FitMate.Core/JsonModels/AiActions/`; enums in `FitMate.DB/Enums`; configs in `FitMate.DB/Configurations` extending `BaseConfiguration<T>` (internal class, calls `base.Configure`).
- **Proposal tools NEVER persist domain entities** (spec §13.2). They only create an `AiAction` in `PendingConfirmation` and return `requiresConfirmation: true` + `aiActionId` + a compact preview.
- **PayloadJson is untrusted.** Confirmation deserializes and re-runs the same validators used at proposal time before anything is created (spec §84).
- **Usage is charged at proposal time** (reserve → commit via `IUsageService`); confirmation charges nothing (spec §48).
- **No nested transactions:** `WorkoutService.CreateAsync` and `WorkoutTemplateService.CreateAsync` already open their own `BeginTransactionAsync`. `AiActionService.ConfirmAsync` therefore does NOT wrap executor calls in an outer transaction — the committed `Executing` status write is the lock (an action stuck in `Executing` after a crash is cleaned by the Plan 11 sweep; it can never double-execute).
- `AppDbContext.SaveChangesAsync()` stamps `DateCreated`/`DateModified` — never set them manually. Concurrency token `Version` is incremented manually on every status transition.
- Plans 03 (exercise ownership/metadata), 04 (`IUsageService`, `SubscriptionFeature`), and 05 (`IAiToolHandler`, `AiToolContext`, `AiConversation`/`AiRun`, `SendAiMessageResponse`, orchestrator) land **before** this plan. Their canonical names come from the roadmap Shared Contracts; wherever an exact member signature could drift, this plan gives concrete best-guess code plus a one-line "verify against …" note — resolve those at execution time, do not invent parallel abstractions.
- Provider neutrality (roadmap D6): nothing in this plan touches OpenAI/Stripe SDKs.
- After backend DTO changes: `dotnet build server/FitMate.Web/FitMate.Web.csproj` regenerates `client/src/types/backend.ts`, then `npm run process-types` in `client/`. **Never write TS interfaces by hand for API models.** After any React/TS change: `cd client && npm run lint` and `npx tsc -b --noEmit`.

```csharp
using FitMate.DB.Configurations.Base;
using FitMate.DB.Entities;
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Metadata.Builders;

namespace FitMate.DB.Configurations;

internal class AiActionConfiguration : BaseConfiguration<AiAction>
{
    public override void Configure(EntityTypeBuilder<AiAction> builder)
    {
        base.Configure(builder);

        // "jsonb" is honored by Npgsql; the Sqlite test provider stores it as TEXT (affinity rules),
        // so the same model works in both. Do NOT use xmin/IsRowVersion — Sqlite cannot emulate it.
        builder.Property(x => x.PayloadJson).IsRequired().HasColumnType("jsonb");
        builder.Property(x => x.ResultJson).HasColumnType("jsonb").IsRequired(false);
        builder.Property(x => x.ValidationSummaryJson).HasColumnType("jsonb").IsRequired(false);
        builder.Property(x => x.FailureReason).HasMaxLength(2000).IsRequired(false);
        builder.Property(x => x.Version).IsConcurrencyToken();

        builder.HasOne(x => x.User)
            .WithMany()
            .HasForeignKey(x => x.UserId)
            .OnDelete(DeleteBehavior.Cascade);

        // FK-only relationships to the Plan 05 AI entities (no navigation properties, so this
        // configuration compiles regardless of their member names).
        builder.HasOne<AiConversation>()
            .WithMany()
            .HasForeignKey(x => x.ConversationId)
            .OnDelete(DeleteBehavior.Cascade);

        builder.HasOne<AiRun>()
            .WithMany()
            .HasForeignKey(x => x.AiRunId)
            .OnDelete(DeleteBehavior.Cascade);

        builder.HasIndex(x => new { x.UserId, x.Status });
        builder.HasIndex(x => x.ConversationId);
        builder.HasIndex(x => x.AiRunId);
    }
}
```

```csharp
using FitMate.DB.Entities;
using FitMate.DB.Enums;
using FitMate.Tests.TestInfrastructure;
using Microsoft.EntityFrameworkCore;

namespace FitMate.Tests.Unit.Services;

public class AiActionConcurrencyTests
{
    [Fact]
    public async Task VersionToken_StaleSave_ThrowsDbUpdateConcurrencyException()
    {
        using var db = new SqliteTestDatabase();
        long actionId;
        await using (var seed = db.CreateContext())
        {
            var (conversationId, runId) =
                await AiActionTestData.SeedConversationAndRunAsync(seed, SqliteTestDatabase.UserId);
            var action = new AiAction
            {
                UserId = SqliteTestDatabase.UserId,
                ConversationId = conversationId,
                AiRunId = runId,
                Type = AiActionType.CreateWorkout,
                Status = AiActionStatus.PendingConfirmation,
                ExpiresAt = DateTime.UtcNow.AddHours(24),
            };
            seed.AiActions.Add(action);
            await seed.SaveChangesAsync();
            actionId = action.Id;
        }

        await using var contextA = db.CreateContext();
        await using var contextB = db.CreateContext();
        var actionA = await contextA.AiActions.SingleAsync(a => a.Id == actionId);
        var actionB = await contextB.AiActions.SingleAsync(a => a.Id == actionId);

        actionA.Status = AiActionStatus.Executing;
        actionA.Version++;
        await contextA.SaveChangesAsync();

        actionB.Status = AiActionStatus.Executing;
        actionB.Version++;
        await Assert.ThrowsAsync<DbUpdateConcurrencyException>(() => contextB.SaveChangesAsync());
    }
}
```

```csharp
using System.Text.Json;
using FitMate.Core.Exceptions;

namespace FitMate.Services.AiActions;

public static class AiActionJson
{
    // Web defaults = camelCase + case-insensitive — matches both tool-call arguments from the
    // model and the payloads persisted by the proposal tools.
    // If Plan 05 already exposes a shared JsonSerializerOptions for tool arguments, reuse it here
    // instead — verify server/FitMate.Services/Ai at execution time.
    public static readonly JsonSerializerOptions SerializerOptions = new(JsonSerializerDefaults.Web);

    public static T Deserialize<T>(string json)
        where T : class
    {
        try
        {
            return JsonSerializer.Deserialize<T>(json, SerializerOptions)
                ?? throw new FitMateException("The action payload is empty.");
        }
        catch (JsonException)
        {
            throw new FitMateException("The action payload is not valid JSON.");
        }
    }

    public static string Serialize<T>(T value) => JsonSerializer.Serialize(value, SerializerOptions);
}
```

```csharp
using FitMate.Core.JsonModels.AiActions;

namespace FitMate.Services.AiActions;

public static class AiProposalValidator
{
    public const int MaxSetsPerExercise = 15;
    private const int SecondsPerSet = 45;
    private const int DefaultRestSeconds = 90;

    public static List<string> ValidateWorkoutExercises(
        IReadOnlyList<ProposedWorkoutExercise> exercises,
        IReadOnlySet<long> visibleExerciseIds)
    {
        var errors = new List<string>();
        if (exercises.Count == 0)
        {
            errors.Add("A workout needs at least one exercise.");
            return errors;
        }

        var duplicateIds = exercises.GroupBy(e => e.ExerciseId)
            .Where(g => g.Count() > 1)
            .Select(g => g.Key);
        foreach (var id in duplicateIds)
        {
            errors.Add($"Exercise {id} appears more than once.");
        }

        for (var index = 0; index < exercises.Count; index++)
        {
            var exercise = exercises[index];
            var position = $"Exercise {index + 1}";

            if (!visibleExerciseIds.Contains(exercise.ExerciseId))
            {
                errors.Add($"{position} references exercise {exercise.ExerciseId}, which does not exist or is not visible to you.");
            }

            if (exercise.Sets.Count is < 1 or > MaxSetsPerExercise)
            {
                errors.Add($"{position} must have between 1 and {MaxSetsPerExercise} sets.");
            }

            foreach (var set in exercise.Sets)
            {
                if (set.Reps is < 1 or > 100)
                {
                    errors.Add($"{position}: reps must be between 1 and 100.");
                }
                if (set.WeightKg is < 0 or > 1000)
                {
                    errors.Add($"{position}: weight must be between 0 and 1000 kg.");
                }
                if (set.Rpe is < 1 or > 10)
                {
                    errors.Add($"{position}: RPE must be between 1 and 10.");
                }
                if (set.RestSeconds is < 0 or > 600)
                {
                    errors.Add($"{position}: rest must be between 0 and 600 seconds.");
                }
            }
        }

        return errors;
    }

    public static List<string> ValidateExercisePayload(ProposeExercisePayload payload)
    {
        var errors = new List<string>();
        if (string.IsNullOrWhiteSpace(payload.Name) || payload.Name.Trim().Length > 200)
        {
            errors.Add("Exercise name is required and must be at most 200 characters.");
        }
        if (payload.PrimaryMuscleGroupId < 1)
        {
            errors.Add("A primary muscle group is required.");
        }
        if (payload.Description?.Length > 2000)
        {
            errors.Add("Description must be at most 2000 characters.");
        }
        if (payload.Aliases.Count > 10)
        {
            errors.Add("At most 10 aliases are allowed.");
        }
        if (payload.Aliases.Any(a => string.IsNullOrWhiteSpace(a) || a.Trim().Length > 200))
        {
            errors.Add("Every alias must be non-empty and at most 200 characters.");
        }
        return errors;
    }

    public static int EstimateDurationMinutes(IReadOnlyList<ProposedWorkoutExercise> exercises)
    {
        var totalSeconds = exercises
            .SelectMany(e => e.Sets)
            .Sum(s => SecondsPerSet + (s.RestSeconds ?? DefaultRestSeconds));
        return Math.Max(1, (int)Math.Round(totalSeconds / 60.0));
    }
}
```

```csharp
        if (rests.Count > 0)
        {
            parts.Add($"rest {rests.Max()}s");
        }
        return string.Join(" · ", parts);
```

```csharp
    public async Task<AiActionModel> RejectAsync(long actionId, long userId)
    {
        var action = await dbContext.AiActions
            .FirstOrDefaultAsync(a => a.Id == actionId && a.UserId == userId)
            ?? throw new FitMateException("AI action not found.");

        if (action.Status == AiActionStatus.Rejected)
        {
            return await MapAsync(action);   // idempotent
        }
        if (action.Status is AiActionStatus.Executed or AiActionStatus.Executing)
        {
            throw new AiActionAlreadyExecutedException();
        }
        if (action.Status == AiActionStatus.Expired || action.ExpiresAt <= DateTime.UtcNow)
        {
            await SweepExpiryAsync(action, userId);
            throw new AiActionExpiredException();
        }
        if (action.Status != AiActionStatus.PendingConfirmation)
        {
            throw new FitMateException("Only pending actions can be rejected.");
        }

        action.Status = AiActionStatus.Rejected;
        action.RejectedAt = DateTime.UtcNow;
        action.Version++;
        await dbContext.SaveChangesAsync(userId);
        return await MapAsync(action);
    }

    private async Task SweepExpiryAsync(AiAction action, long userId)
    {
        if (action.Status == AiActionStatus.PendingConfirmation && action.ExpiresAt <= DateTime.UtcNow)
        {
            action.Status = AiActionStatus.Expired;
            action.Version++;
            await dbContext.SaveChangesAsync(userId);
        }
    }

    private async Task<AiActionModel> MapAsync(AiAction action)
    {
        var validationSummary = string.IsNullOrWhiteSpace(action.ValidationSummaryJson)
            ? null
            : AiActionJson.Deserialize<AiActionValidationSummaryModel>(action.ValidationSummaryJson);
        var result = string.IsNullOrWhiteSpace(action.ResultJson)
            ? null
            : AiActionJson.Deserialize<AiActionExecutionResult>(action.ResultJson);

        return new AiActionModel
        {
            Id = action.Id,
            Type = action.Type,
            Status = action.Status,
            Preview = await AiActionPreviewBuilder.BuildAsync(dbContext, action),
            ValidationSummary = validationSummary,
            ExpiresAt = action.ExpiresAt,
            ExecutedAt = action.ExecutedAt,
            FailureReason = action.FailureReason,
            CreatedEntityId = result?.CreatedEntityId,
            CreatedEntityName = result?.CreatedEntityName,
        };
    }
```

```csharp
    public async Task<AiActionModel> ConfirmAsync(long actionId, long userId)
    {
        var action = await dbContext.AiActions
            .FirstOrDefaultAsync(a => a.Id == actionId && a.UserId == userId)
            ?? throw new FitMateException("AI action not found.");

        switch (action.Status)
        {
            case AiActionStatus.Executed:
                return await MapAsync(action);                       // idempotent re-confirm
            case AiActionStatus.Executing:
                throw new AiActionAlreadyExecutedException();
            case AiActionStatus.Expired:
                throw new AiActionExpiredException();
            case AiActionStatus.Rejected:
                throw new FitMateException("This action was rejected and can no longer be confirmed.");
            case AiActionStatus.Failed:
                throw new FitMateException("This action failed and can no longer be confirmed. Ask the coach to propose it again.");
        }

        if (action.ExpiresAt <= DateTime.UtcNow)
        {
            action.Status = AiActionStatus.Expired;
            action.Version++;
            await dbContext.SaveChangesAsync(userId);
            throw new AiActionExpiredException();
        }

        // The guarded transition — the Version concurrency token makes exactly one confirm win.
        action.Status = AiActionStatus.Executing;
        action.ConfirmedAt = DateTime.UtcNow;
        action.Version++;
        try
        {
            await dbContext.SaveChangesAsync(userId);
        }
        catch (DbUpdateConcurrencyException)
        {
            await dbContext.Entry(action).ReloadAsync();
            if (action.Status == AiActionStatus.Executed)
            {
                return await MapAsync(action);                       // the other confirm won
            }
            throw new AiActionAlreadyExecutedException();
        }

        var executor = executors.FirstOrDefault(e => e.ActionType == action.Type)
            ?? throw new FitMateException($"No executor is registered for action type {action.Type}.");

        try
        {
            // Executors revalidate the (untrusted) payload from scratch and create the entity
            // through the real domain service, which opens its own transaction (see Global
            // Constraints — no outer transaction here on purpose).
            var result = await executor.ExecuteAsync(action, userId, CancellationToken.None);
            action.ResultJson = AiActionJson.Serialize(result);
            action.Status = AiActionStatus.Executed;
            action.ExecutedAt = DateTime.UtcNow;
            action.Version++;
            await dbContext.SaveChangesAsync(userId);
            return await MapAsync(action);
        }
        catch (Exception exception)
        {
            action.Status = AiActionStatus.Failed;
            action.FailureReason = exception.Message;
            action.Version++;
            await dbContext.SaveChangesAsync(userId);
            throw new FitMateException($"Confirming the action failed: {exception.Message}");
        }
    }
```

```csharp
using FitMate.Core.JsonModels.AiActions;
using FitMate.DB;
using FitMate.DB.Enums;
using FitMate.Services.AiActions;
using FitMate.Services.Subscriptions;   // verify Plan 04 namespace

namespace FitMate.Services.Ai.Tools;

internal static class ProposalToolShared
{
    internal static async Task<AiToolExecutionResult> CreateWorkoutShapedActionAsync(
        AppDbContext dbContext,
        IAiActionService aiActionService,
        IUsageService usageService,
        AiToolContext context,
        List<ProposedWorkoutExercise> exercises,
        AiActionType type,
        string payloadJson)
    {
        var visibleIds = await ExerciseVisibilityQuery.GetVisibleIdsAsync(
            dbContext, exercises.Select(e => e.ExerciseId).ToList(), context.UserId);
        var errors = AiProposalValidator.ValidateWorkoutExercises(exercises, visibleIds);
        if (errors.Count > 0)
        {
            return new AiToolExecutionResult
            {
                Success = false,
                ErrorCode = "validation_failed",
                ErrorMessage = string.Join(" ", errors),
                Data = new { errors },
            };
        }

        var warnings = new List<string>();
        var estimatedMinutes = AiProposalValidator.EstimateDurationMinutes(exercises);
        if (estimatedMinutes > 180)
        {
            warnings.Add($"This session is estimated at ~{estimatedMinutes} minutes — consider splitting it.");
        }

        // Spec §35/§48: charge AiWorkoutGeneration at PROPOSAL time; confirmation charges nothing.
        var reservation = await usageService.ReserveAsync(context.UserId, SubscriptionFeature.AiWorkoutGeneration, 1);
        AiActionModel action;
        try
        {
            action = await aiActionService.CreatePendingAsync(new CreateAiActionRequest
            {
                ConversationId = context.ConversationId,
                AiRunId = context.AiRunId,
                Type = type,
                PayloadJson = payloadJson,
                ValidationSummary = new AiActionValidationSummaryModel { Warnings = warnings },
            }, context.UserId);
            await usageService.CommitAsync(reservation.Id);
        }
        catch
        {
            await usageService.ReleaseAsync(reservation.Id);
            throw;
        }

        return new AiToolExecutionResult
        {
            Success = true,
            RequiresConfirmation = true,
            AiActionId = action.Id,
            Data = new
            {
                status = "pending_confirmation",
                preview = action.Preview,
                warnings,
                estimatedDurationMinutes = estimatedMinutes,
            },
        };
    }
```

```csharp
          "required": ["name", "primaryMuscleGroupId", "isPublic"]

        """;

    public string Name => "propose_exercise";

    public AiToolDefinition Definition => new()
    {

        Description = "Propose creating a new exercise when no existing exercise matches. "

    public async Task<AiToolExecutionResult> ExecuteAsync(string argumentsJson, AiToolContext context, CancellationToken cancellationToken)
    {
        var payload = AiActionJson.Deserialize<ProposeExercisePayload>(argumentsJson);
        var errors = AiProposalValidator.ValidateExercisePayload(payload);
        var muscleGroupExists = await dbContext.MuscleGroups.AnyAsync(m => m.Id == payload.PrimaryMuscleGroupId);
        if (!muscleGroupExists)
        {
            errors.Add($"Muscle group {payload.PrimaryMuscleGroupId} does not exist.");
        }
        if (errors.Count > 0)
        {
            return new AiToolExecutionResult
            {
                Success = false,
                ErrorCode = "validation_failed",

        if (duplicates.Count > 0)

            ConversationId = context.ConversationId,
            AiRunId = context.AiRunId,

    private async Task<List<DuplicateExerciseCandidateModel>> FindDuplicateCandidatesAsync(string name, long userId)
    {
        var normalized = name.Trim().ToLower();

        var byName = await dbContext.Exercises
            .AsNoTracking()
            .Where(e => e.UserId == null || e.UserId == userId || e.IsPublic)
            .Where(e => e.Name.ToLower().Contains(normalized) || normalized.Contains(e.Name.ToLower()))
            .Select(e => new DuplicateExerciseCandidateModel { ExerciseId = e.Id, Name = e.Name, IsGlobal = e.UserId == null })

            .AsNoTracking()

            .Where(a => a.Name.ToLower().Contains(normalized) || normalized.Contains(a.Name.ToLower()))

                ExerciseId = a.ExerciseId,
                Name = a.Exercise.Name,
                IsGlobal = a.Exercise.UserId == null,
                MatchedAlias = a.Name,
            })
            .Take(5)
            .ToListAsync();

        return byName.Concat(byAlias).DistinctBy(c => c.ExerciseId).Take(5).ToList();
```

```ts
import { useState } from "react";
import { AxiosError } from "axios";
import { aiActionService } from "@/services/aiActionService";
import { AiActionStatus } from "@/types";
import type { AiAction } from "@/types";

type BusyKind = "confirm" | "reject" | null;

function extractError(error: unknown): string {
  if (error instanceof AxiosError) {
    const data = error.response?.data as { error?: string } | undefined;
    if (data?.error) {
      return data.error;
    }
  }
  return "Something went wrong. Please try again.";
}

export function useAiActionCard(initial: AiAction) {
  const [action, setAction] = useState<AiAction>(initial);
  const [busy, setBusy] = useState<BusyKind>(null);
  const [error, setError] = useState<string | null>(null);

  async function refresh() {
    try {
      const response = await aiActionService.getById(action.id);
      if (response.data.success && response.data.data) {
        setAction(response.data.data);
      }
    } catch {
      // Keep the last known state; the error message already explains what happened.
    }
  }

  async function run(kind: "confirm" | "reject") {
    setBusy(kind);
    setError(null);
    try {
      const response =
        kind === "confirm"
          ? await aiActionService.confirm(action.id)
          : await aiActionService.reject(action.id);
      if (response.data.success && response.data.data) {
        setAction(response.data.data);
      } else {
        setError(response.data.error ?? "Something went wrong.");
      }
    } catch (requestError) {
      // 409 (already executed) / 410 (expired) / 400 — the action changed server-side;
      // refetch so the chip shows the real status.
      setError(extractError(requestError));
      await refresh();
    } finally {
      setBusy(null);
    }
  }

  return {
    action,
    busy,
    error,
    isPending: action.status === AiActionStatus.PendingConfirmation,
    confirm: async () => run("confirm"),
    reject: async () => run("reject"),
  };
}
```
