# AI Core + Observability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Users chat with an AI training coach at `/ai-coach` that answers questions about their real training data through an allow-listed set of read-only tools, with every run, tool call, token count and cost persisted for observability — no mutation tools yet.

**Architecture:** A new provider-neutral `FitMate.Integrations` project wraps the official OpenAI .NET SDK behind `IAiCompletionProvider`/`IAiImageProvider` (roadmap D6: no OpenAI types leak out). `FitMate.Services/AI` hosts the orchestration loop (`AiOrchestrator`): entitlement check → usage reservation → `AiRun` start → bounded tool loop through `AiToolRegistry` → assistant message persisted → usage committed. All conversations/messages/runs/tool executions land in new `FitMate.DB` entities; tool args/results pass through `AiRedactionService` before storage. The React `/ai-coach` page consumes `api/ai/*` with generated types only.

**Tech Stack:** .NET 9, EF Core + Npgsql (Sqlite in tests), official `OpenAI` NuGet package (inside FitMate.Integrations only), xUnit + `SqliteTestDatabase`, Serilog structured logging, React 19 + Tailwind 4 + existing shared components, Reinforced.Typings type export.

## Global Constraints

- Follow repo conventions (roadmap D4): services take `(request, long userId)` with **no CancellationToken** — EXCEPT `FitMate.Integrations` provider interfaces, which DO take `CancellationToken` (network calls). Controllers extend `BaseApiController` and use `this.ReturnJson(...)`/`this.ReturnJsonError(...)`; DTOs in `FitMate.Core/JsonModels/AI/`; enums in `FitMate.DB/Enums`; entity configs in `FitMate.DB/Configurations`; DI in `Program.cs` (~line 250–263 block).
- **Provider neutrality (roadmap D6):** nothing outside `server/FitMate.Integrations` may reference OpenAI SDK types. `FitMate.Core` must NOT reference `FitMate.Integrations` (Integrations MAY reference Core — see Task 1 note).
- **Never log prompts or message content** to Serilog/general logs (spec §69). Log only structured props: `UserId`, `ConversationId`, `AiRunId`, `ToolName`, `SubscriptionPlanCode`, `Provider`, `Model`, `ProviderRequestId`.
- **Redact before persisting:** tool `ArgumentsJson`/`ResultJson` and tool-trace `AiMessage` content pass through `IAiRedactionService` BEFORE `SaveChangesAsync` (spec §56).
- No real model names or secrets committed. Model names + OpenAI key come from env/user-secrets/`appsettings.Local.json` (spec §5).
- Consumed contracts from earlier plans (already merged when this plan runs): Plan 01 `IProgramPlanService` (`GetActiveAsync`, `GetCalendarAsync`), Plan 03 `UserTrainingProfile` + `ExerciseAlias` entities, Plan 04 `IEntitlementService`/`IUsageService`/`SubscriptionFeature`. Where a Plan 03/04 member name is a best guess, the step carries a "verify against" note — resolve it at execution time, do not skip.
- `AppDbContext.SaveChangesAsync()` stamps `DateCreated`/`DateModified` — never set them manually.
- One migration only: `AddAiCoreEntities`. After backend DTO changes: `dotnet build server/FitMate.Web/FitMate.Web.csproj` then `cd client && npm run process-types`. After any frontend change: `cd client && npm run lint && npx tsc -b --noEmit`.

- [ ] **Step 2: Write `OpenAiCompletionProvider`** — the ONLY place (besides `OpenAiImageProvider`) allowed to `using OpenAI.*`

```csharp
using FitMate.Core.Exceptions;
using FitMate.Integrations.AI.Abstractions;
using FitMate.Integrations.AI.Models;
using Microsoft.Extensions.Options;
using OpenAI;
using OpenAI.Chat;
using System.ClientModel;

namespace FitMate.Integrations.AI.OpenAI;

public class OpenAiCompletionProvider : IAiCompletionProvider
{
    private readonly Lazy<OpenAIClient> client;

    public OpenAiCompletionProvider(IOptions<OpenAiOptions> options)
    {
        client = new Lazy<OpenAIClient>(() =>
        {
            var apiKey = options.Value.ApiKey;
            if (string.IsNullOrWhiteSpace(apiKey))
            {
                throw new AiProviderException("OpenAI API key is not configured.");
            }

            return new OpenAIClient(apiKey);
        });
    }

    public string ProviderName => "OpenAI";

    public async Task<AiCompletionResponse> CompleteAsync(AiCompletionRequest request, CancellationToken cancellationToken = default)
    {
        var chatClient = client.Value.GetChatClient(request.Model);
        var messages = request.Messages.Select(ToChatMessage).ToList();
        var options = new ChatCompletionOptions();

        if (request.MaxOutputTokens.HasValue)
        {
            options.MaxOutputTokenCount = request.MaxOutputTokens.Value;
        }

        if (request.Temperature.HasValue)
        {
            options.Temperature = request.Temperature.Value;
        }

        foreach (var tool in request.Tools)
        {
            options.Tools.Add(ChatTool.CreateFunctionTool(
                tool.Name,
                tool.Description,
                BinaryData.FromString(tool.ParametersJsonSchema)));
        }

        try
        {
            ChatCompletion completion = await chatClient.CompleteChatAsync(messages, options, cancellationToken);
            return ToResponse(completion);
        }
        catch (ClientResultException exception)
        {
            throw new AiProviderException("The AI provider request failed.", exception);
        }
    }

    internal static AiCompletionResponse ToResponse(ChatCompletion completion) => new()
    {
        Text = string.Concat(completion.Content.Select(part => part.Text)),
        ToolCalls = completion.ToolCalls
            .Select(call => new AiProviderToolCall
            {
                Id = call.Id,
                Name = call.FunctionName,
                ArgumentsJson = call.FunctionArguments.ToString(),
            })
            .ToList(),
        Usage = new AiProviderUsage
        {
            InputTokens = completion.Usage?.InputTokenCount ?? 0,
            OutputTokens = completion.Usage?.OutputTokenCount ?? 0,
            CachedInputTokens = completion.Usage?.InputTokenDetails?.CachedTokenCount ?? 0,
        },
        ProviderRequestId = completion.Id,
        Model = completion.Model,
    };

    internal static ChatMessage ToChatMessage(AiProviderMessage message) => message.Role switch
    {
        AiProviderRole.System => new SystemChatMessage(message.Text),
        AiProviderRole.User => ToUserMessage(message),
        AiProviderRole.Assistant when message.ToolCalls.Count > 0 => new AssistantChatMessage(
            message.ToolCalls.Select(call => ChatToolCall.CreateFunctionToolCall(
                call.Id, call.Name, BinaryData.FromString(call.ArgumentsJson)))),
        AiProviderRole.Assistant => new AssistantChatMessage(message.Text),
        AiProviderRole.Tool => new ToolChatMessage(message.ToolCallId, message.Text),
        _ => throw new AiProviderException($"Unsupported AI message role '{message.Role}'."),
    };

    private static UserChatMessage ToUserMessage(AiProviderMessage message)
    {
        if (message.Images.Count == 0)
        {
            return new UserChatMessage(message.Text);
        }

        var parts = new List<ChatMessageContentPart>();
        if (!string.IsNullOrEmpty(message.Text))
        {
            parts.Add(ChatMessageContentPart.CreateTextPart(message.Text));
        }

        foreach (var image in message.Images)
        {
            parts.Add(image.Url != null
                ? ChatMessageContentPart.CreateImagePart(new Uri(image.Url))
                : ChatMessageContentPart.CreateImagePart(
                    BinaryData.FromBytes(Convert.FromBase64String(image.Base64Data
                        ?? throw new AiProviderException("Image content requires Url or Base64Data."))),
                    image.MediaType));
        }

        return new UserChatMessage(parts);
    }
}

using FitMate.Core.Exceptions;
using FitMate.Integrations.AI.Abstractions;
using FitMate.Integrations.AI.Models;
using Microsoft.Extensions.Options;
using OpenAI;
using OpenAI.Images;

namespace FitMate.Integrations.AI.OpenAI;

public class OpenAiImageProvider : IAiImageProvider
{
    private readonly Lazy<OpenAIClient> client;

    public OpenAiImageProvider(IOptions<OpenAiOptions> options)
    {
        client = new Lazy<OpenAIClient>(() =>
        {
            var apiKey = options.Value.ApiKey;
            if (string.IsNullOrWhiteSpace(apiKey))
            {
                throw new AiProviderException("OpenAI API key is not configured.");
            }

            return new OpenAIClient(apiKey);
        });
    }

    public string ProviderName => "OpenAI";

    public async Task<AiGeneratedImageResult> GenerateAsync(AiImageGenerationRequest request, CancellationToken cancellationToken = default)
    {
        var imageClient = client.Value.GetImageClient(request.Model);
        var options = new ImageGenerationOptions
        {
            Size = new GeneratedImageSize(request.Width, request.Height),
            ResponseFormat = GeneratedImageFormat.Bytes,
        };

        try
        {
            GeneratedImage image = await imageClient.GenerateImageAsync(request.Prompt, options, cancellationToken);
            return new AiGeneratedImageResult
            {
                ImageBytes = image.ImageBytes?.ToArray(),
                Url = image.ImageUri?.ToString(),
                RevisedPrompt = image.RevisedPrompt,
                Model = request.Model,
            };
        }
        catch (ClientResultException exception)
        {
            throw new AiProviderException("The AI image generation request failed.", exception);
        }
    }

using Microsoft.Extensions.Configuration;

namespace FitMate.Core.Settings;

public static class AiOptionsValidator
{
    private static readonly string[] RequiredProductionKeys =
    [
        "DefaultModel",
        "FastModel",
        "ReasoningModel",
        "VisionModel",
        "ImageModel",
        "OpenAI:ApiKey",
    ];

    /// Fails fast on missing production AI configuration, mirroring the existing
    /// connection-string / JWT signing-key checks in Program.cs. No-op outside production.
    public static void Validate(IConfiguration configuration, bool isProduction)
    {
        if (!isProduction)
        {
            return;
        }

        var section = configuration.GetSection(AiOptions.SectionName);
        foreach (var key in RequiredProductionKeys)
        {
            if (string.IsNullOrWhiteSpace(section[key]))
            {
                throw new InvalidOperationException($"AI configuration value 'AI:{key}' is required in production.");
            }
        }
    }
}

```csharp
using System.Text.RegularExpressions;

namespace FitMate.Services.AI;

public class AiRedactionService : IAiRedactionService
{
    private const string Replacement = "[REDACTED]";
    private static readonly TimeSpan MatchTimeout = TimeSpan.FromMilliseconds(250);

    private static readonly Regex JwtRegex = new(
        @"eyJ[A-Za-z0-9_-]{5,}\.[A-Za-z0-9_-]{5,}\.[A-Za-z0-9_-]{5,}",
        RegexOptions.Compiled, MatchTimeout);

    private static readonly Regex BearerRegex = new(
        @"(?i)bearer\s+[A-Za-z0-9._~+/=-]{8,}",
        RegexOptions.Compiled, MatchTimeout);

    private static readonly Regex ApiKeyRegex = new(
        @"\b(?:sk|rk|key|api)-[A-Za-z0-9_-]{16,}\b",
        RegexOptions.Compiled, MatchTimeout);

    private static readonly Regex StripeKeyRegex = new(
        @"\b(?:sk_live|pk_live|sk_test|pk_test|whsec)_[A-Za-z0-9]{8,}\b",
        RegexOptions.Compiled, MatchTimeout);

    private static readonly Regex CookieHeaderRegex = new(
        @"(?i)\b(cookie|set-cookie)\s*:\s*[^\r\n""]+",
        RegexOptions.Compiled, MatchTimeout);

    private static readonly Regex SignedBlobSigRegex = new(
        @"(?i)(sig=)[^&\s""']+",
        RegexOptions.Compiled, MatchTimeout);

    private static readonly Regex HexSecretRegex = new(
        @"\b[0-9a-fA-F]{32,}\b",
        RegexOptions.Compiled, MatchTimeout);

    private static readonly Regex Base64SecretRegex = new(
        @"[A-Za-z0-9+/]{40,}={0,2}",
        RegexOptions.Compiled, MatchTimeout);

    private static readonly Regex JsonSensitiveFieldRegex = new(
        @"(?i)""(password|passwd|secret|token|accesstoken|refreshtoken|apikey|api_key|connectionstring|connection_string|authorization)""\s*:\s*""(?:[^""\\]|\\.)*""",
        RegexOptions.Compiled, MatchTimeout);

    public string RedactText(string text)
    {
        if (string.IsNullOrEmpty(text))
        {
            return text ?? string.Empty;
        }

        var result = text;
        result = JwtRegex.Replace(result, Replacement);
        result = BearerRegex.Replace(result, Replacement);
        result = ApiKeyRegex.Replace(result, Replacement);
        result = StripeKeyRegex.Replace(result, Replacement);
        result = CookieHeaderRegex.Replace(result, $"$1: {Replacement}");
        result = SignedBlobSigRegex.Replace(result, $"$1{Replacement}");
        result = HexSecretRegex.Replace(result, Replacement);
        result = Base64SecretRegex.Replace(result, Replacement);
        return result;
    }

    public string RedactJson(string json)
    {
        if (string.IsNullOrEmpty(json))
        {
            return json ?? string.Empty;
        }

        var result = JsonSensitiveFieldRegex.Replace(json, $"\"$1\":\"{Replacement}\"");
        return RedactText(result);
    }
}

```csharp
using FitMate.Core.Exceptions;
using FitMate.Core.JsonModels.AI;
using FitMate.DB;
using FitMate.DB.Entities;
using FitMate.DB.Enums;
using Microsoft.EntityFrameworkCore;

namespace FitMate.Services.AI;

public class AiConversationService : IAiConversationService
{
    private readonly AppDbContext dbContext;

    public AiConversationService(AppDbContext dbContext)
    {
        this.dbContext = dbContext;
    }

    public async Task<IReadOnlyList<AiConversationSummaryModel>> ListAsync(long userId)
    {
        return await dbContext.AiConversations
            .AsNoTracking()
            .Where(c => c.UserId == userId && c.Status != AiConversationStatus.Deleted)
            .OrderByDescending(c => c.LastMessageAt)
            .Select(c => new AiConversationSummaryModel
            {
                Id = c.Id,
                Title = c.Title,
                Status = c.Status,
                LastMessageAt = c.LastMessageAt,
                MessageCount = c.Messages.Count(m => m.Role == AiMessageRole.User || m.Role == AiMessageRole.Assistant),
            })
            .ToListAsync();
    }

    public async Task<AiConversationModel> CreateAsync(CreateAiConversationRequest request, long userId)
    {
        var conversation = new AiConversation
        {
            UserId = userId,
            Title = string.IsNullOrWhiteSpace(request.Title) ? null : request.Title.Trim(),
            Status = AiConversationStatus.Active,
            LastMessageAt = DateTime.UtcNow,
        };
        dbContext.AiConversations.Add(conversation);
        await dbContext.SaveChangesAsync();
        return ToModel(conversation, []);
    }

    public async Task<AiConversationModel?> GetByIdAsync(long conversationId, long userId)
    {
        var conversation = await dbContext.AiConversations
            .AsNoTracking()
            .Include(c => c.Messages)
            .FirstOrDefaultAsync(c => c.Id == conversationId
                && c.UserId == userId
                && c.Status != AiConversationStatus.Deleted);
        return conversation == null
            ? null
            : ToModel(conversation, conversation.Messages.OrderBy(m => m.Id).ToList());
    }

    public async Task<bool> DeleteAsync(long conversationId, long userId)
    {
        var conversation = await LoadOwnedAsync(conversationId, userId);
        if (conversation == null)
        {
            return false;
        }

        conversation.Status = AiConversationStatus.Deleted;
        await dbContext.SaveChangesAsync();
        return true;
    }

    public Task<AiMessageModel> AddUserMessageAsync(long conversationId, string content, long userId) =>
        AddMessageAsync(conversationId, userId, AiMessageRole.User, content, null, null, null);

    public Task<AiMessageModel> AddAssistantMessageAsync(long conversationId, string content, long userId, string? metadataJson = null) =>
        AddMessageAsync(conversationId, userId, AiMessageRole.Assistant, content, null, null, metadataJson);

    public Task AddToolCallMessageAsync(long conversationId, long userId, string toolName, string toolCallId, string argumentsJson) =>
        AddMessageAsync(conversationId, userId, AiMessageRole.ToolCall, argumentsJson, toolName, toolCallId, null);

    public Task AddToolResultMessageAsync(long conversationId, long userId, string toolName, string toolCallId, string resultJson) =>
        AddMessageAsync(conversationId, userId, AiMessageRole.ToolResult, resultJson, toolName, toolCallId, null);

    public async Task<IReadOnlyList<AiMessage>> GetContextMessagesAsync(long conversationId, long userId, int maxMessages)
    {
        var messages = await dbContext.AiMessages
            .AsNoTracking()
            .Where(m => m.ConversationId == conversationId && m.UserId == userId)
            .OrderByDescending(m => m.Id)
            .Take(maxMessages)
            .ToListAsync();
        messages.Reverse();

        // A truncated window must not start mid tool exchange — the provider rejects orphan tool messages.
        while (messages.Count > 0 && messages[0].Role is AiMessageRole.ToolCall or AiMessageRole.ToolResult)
        {
            messages.RemoveAt(0);
        }

        return messages;
    }

    public async Task SetTitleIfEmptyAsync(long conversationId, long userId, string title)
    {
        var conversation = await LoadOwnedAsync(conversationId, userId);
        if (conversation == null || !string.IsNullOrWhiteSpace(conversation.Title))
        {
            return;
        }

        var trimmed = title.Trim();
        conversation.Title = trimmed.Length <= 60 ? trimmed : trimmed[..57] + "...";
        await dbContext.SaveChangesAsync();
    }

    private async Task<AiMessageModel> AddMessageAsync(
        long conversationId, long userId, AiMessageRole role, string content,
        string? toolName, string? toolCallId, string? metadataJson)
    {
        var conversation = await LoadOwnedAsync(conversationId, userId)
            ?? throw new FitMateException("Conversation not found.");

        var message = new AiMessage
        {
            ConversationId = conversationId,
            UserId = userId,
            Role = role,
            Content = content,
            ToolName = toolName,
            ToolCallId = toolCallId,
            MetadataJson = metadataJson,
        };
        dbContext.AiMessages.Add(message);
        conversation.LastMessageAt = DateTime.UtcNow;
        await dbContext.SaveChangesAsync();
        return ToMessageModel(message);
    }

    private Task<AiConversation?> LoadOwnedAsync(long conversationId, long userId) =>
        dbContext.AiConversations.FirstOrDefaultAsync(c => c.Id == conversationId
            && c.UserId == userId
            && c.Status != AiConversationStatus.Deleted);

    private static AiConversationModel ToModel(AiConversation conversation, List<AiMessage> messages) => new()
    {
        Id = conversation.Id,
        Title = conversation.Title,
        Status = conversation.Status,
        LastMessageAt = conversation.LastMessageAt,
        Messages = messages.Select(ToMessageModel).ToList(),
    };

    private static AiMessageModel ToMessageModel(AiMessage message) => new()
    {
        Id = message.Id,
        Role = message.Role,
        Content = message.Content,
        ToolName = message.ToolName,
        DateCreated = message.DateCreated,
    };
}

```csharp
using FitMate.Core.Exceptions;
using FitMate.DB;
using FitMate.DB.Entities;
using FitMate.DB.Enums;
using FitMate.Integrations.AI.Models;
using FitMate.Integrations.AI.Serialization;
using Microsoft.Extensions.Logging;
using System.Diagnostics;
using System.Text.Json;

namespace FitMate.Services.AI.Tools;

public class AiToolRegistry : IAiToolRegistry
{
    private readonly AppDbContext dbContext;
    private readonly IAiRedactionService redactionService;
    private readonly IReadOnlyDictionary<string, IAiToolHandler> handlers;
    private readonly ILogger<AiToolRegistry> logger;

    public AiToolRegistry(
        AppDbContext dbContext,
        IAiRedactionService redactionService,
        IEnumerable<IAiToolHandler> toolHandlers,
        ILogger<AiToolRegistry> logger)
    {
        this.dbContext = dbContext;
        this.redactionService = redactionService;
        this.logger = logger;
        handlers = toolHandlers.ToDictionary(h => h.Name, StringComparer.Ordinal);
    }

    public IReadOnlyList<AiToolDefinition> GetDefinitions(AiToolContext context) =>
        handlers.Values
            .Where(h => h.IsAvailable(context))
            .Select(h => h.Definition)
            .OrderBy(d => d.Name)
            .ToList();

    public async Task<AiToolExecutionResult> ExecuteAsync(AiProviderToolCall toolCall, AiToolContext context, CancellationToken cancellationToken)
    {
        var argumentsJson = string.IsNullOrWhiteSpace(toolCall.ArgumentsJson) ? "{}" : toolCall.ArgumentsJson;
        var execution = new AiToolExecution
        {
            AiRunId = context.AiRunId,
            ToolCallId = toolCall.Id,
            ToolName = toolCall.Name,
            ArgumentsJson = redactionService.RedactJson(argumentsJson),
            Status = AiToolExecutionStatus.Running,
            StartedAt = DateTime.UtcNow,
        };
        dbContext.AiToolExecutions.Add(execution);
        await dbContext.SaveChangesAsync();

        if (!handlers.TryGetValue(toolCall.Name, out var handler))
        {
            await RecordAsync(execution, AiToolExecutionStatus.Rejected, null, "tool_not_found",
                $"AI tool '{toolCall.Name}' is not registered.");
            logger.LogWarning("Rejected unknown AI tool {ToolName} for run {AiRunId}", toolCall.Name, context.AiRunId);
            throw new AiToolNotFoundException(toolCall.Name);
        }

        if (!handler.IsAvailable(context))
        {
            await RecordAsync(execution, AiToolExecutionStatus.Rejected, null, "tool_not_available",
                $"AI tool '{toolCall.Name}' is not available for this user.");
            return Failure("tool_not_available", $"The tool '{toolCall.Name}' is not available.");
        }

        try
        {
            using var _ = JsonDocument.Parse(argumentsJson);
        }
        catch (JsonException)
        {
            await RecordAsync(execution, AiToolExecutionStatus.Rejected, null, "invalid_arguments",
                "Tool arguments were not valid JSON.");
            return Failure("invalid_arguments", "Tool arguments were not valid JSON.");
        }

        var stopwatch = Stopwatch.StartNew();
        try
        {
            var result = await handler.ExecuteAsync(argumentsJson, context, cancellationToken);
            stopwatch.Stop();
            execution.DurationMilliseconds = (int)stopwatch.ElapsedMilliseconds;
            await RecordAsync(
                execution,
                result.Success ? AiToolExecutionStatus.Completed : AiToolExecutionStatus.Failed,
                redactionService.RedactJson(AiJsonSerializer.Serialize(result)),
                result.ErrorCode,
                result.ErrorMessage);
            return result;
        }
        catch (Exception exception) when (exception is not OperationCanceledException)
        {
            stopwatch.Stop();
            execution.DurationMilliseconds = (int)stopwatch.ElapsedMilliseconds;
            await RecordAsync(execution, AiToolExecutionStatus.Failed, null, "tool_failed", exception.Message);
            logger.LogWarning(exception, "AI tool {ToolName} failed for run {AiRunId}", toolCall.Name, context.AiRunId);
            return Failure("tool_failed", "The tool execution failed.");
        }
    }

    private async Task RecordAsync(AiToolExecution execution, AiToolExecutionStatus status, string? resultJson, string? errorCode, string? errorMessage)
    {
        execution.Status = status;
        execution.ResultJson = resultJson;
        execution.ErrorCode = errorCode;
        execution.ErrorMessage = errorMessage;
        execution.CompletedAt = DateTime.UtcNow;
        await dbContext.SaveChangesAsync();
    }

    private static AiToolExecutionResult Failure(string code, string message) =>
        new() { Success = false, ErrorCode = code, ErrorMessage = message };
}

```csharp
using FitMate.Integrations.AI.Models;

namespace FitMate.Services.AI;

public interface IAiCostCalculator
{
    /// Cost in the pricing table's currency, using the row effective at `occurredAt`.
    /// Returns null when no pricing row matches (cost stays unknown rather than wrong).
    Task<decimal?> EstimateAsync(string provider, string model, AiProviderUsage usage, DateTime occurredAt);
}

public interface IAiRunService
{
    Task<AiRun> StartAsync(long userId, long conversationId, string provider, string model, string promptVersion);
    Task AddUsageAsync(long runId, AiProviderUsage usage, string? providerRequestId);
    Task IncrementToolCallCountAsync(long runId, int count);
    Task CompleteAsync(long runId, long assistantMessageId);
    Task FailAsync(long runId, Exception exception);
    Task MarkLimitExceededAsync(long runId, string errorCode, string errorMessage);
}
```

Rules:

- `StartAsync` writes `Status = Running`, `StartedAt = DateTime.UtcNow`.
- `AddUsageAsync` **accumulates** (a run makes several provider calls): `InputTokens += …`, `OutputTokens += …`, `CachedInputTokens += …`, keeps the latest non-null `ProviderRequestId`, and recomputes `EstimatedCost` from the running totals.
- `CompleteAsync` sets `Status = Completed`, `AssistantMessageId`, `CompletedAt`, `DurationMilliseconds = (CompletedAt - StartedAt).TotalMilliseconds`.
- `FailAsync` sets `Status = Failed`, `ErrorCode` = the exception type name, `ErrorMessage` = `exception.Message` **passed through `IAiRedactionService.RedactText`**, `CompletedAt`, duration.
- `MarkLimitExceededAsync` sets `Status = LimitExceeded` with the given code/message.
- Historical pricing: `EstimateAsync` matches `EffectiveFrom <= occurredAt && (EffectiveTo == null || EffectiveTo > occurredAt)` (spec §70).

using FitMate.DB;
using FitMate.Integrations.AI.Models;
using Microsoft.EntityFrameworkCore;

namespace FitMate.Services.AI;

public class AiCostCalculator : IAiCostCalculator
{
    private const decimal TokensPerMillion = 1_000_000m;

    private readonly AppDbContext dbContext;

    public AiCostCalculator(AppDbContext dbContext)
    {
        this.dbContext = dbContext;
    }

    public async Task<decimal?> EstimateAsync(string provider, string model, AiProviderUsage usage, DateTime occurredAt)
    {
        var pricing = await dbContext.AiModelPricings
            .AsNoTracking()
            .Where(p => p.Provider == provider
                && p.Model == model
                && p.EffectiveFrom <= occurredAt
                && (p.EffectiveTo == null || p.EffectiveTo > occurredAt))
            .OrderByDescending(p => p.EffectiveFrom)
            .FirstOrDefaultAsync();

        if (pricing == null)
        {
            return null;
        }

        var cost =
            (usage.InputTokens / TokensPerMillion * pricing.InputCostPerMillionTokens)
            + (usage.CachedInputTokens / TokensPerMillion * pricing.CachedInputCostPerMillionTokens)
            + (usage.OutputTokens / TokensPerMillion * pricing.OutputCostPerMillionTokens);

        return Math.Round(cost, 6);
    }
}

namespace FitMate.Services.AI;

public class AiRunService : IAiRunService

    public AiRunService(
        AppDbContext dbContext,

        this.dbContext = dbContext;
        this.costCalculator = costCalculator;
        this.redactionService = redactionService;

    public async Task<AiRun> StartAsync(long userId, long conversationId, string provider, string model, string promptVersion)
    {
        var run = new AiRun
        {
            UserId = userId,
            ConversationId = conversationId,
            Status = AiRunStatus.Running,
            Provider = provider,
            Model = model,
            PromptVersion = promptVersion,
            StartedAt = DateTime.UtcNow,
        };

        dbContext.AiRuns.Add(run);
        await dbContext.SaveChangesAsync();
        return run;
    }

    public async Task AddUsageAsync(long runId, AiProviderUsage usage, string? providerRequestId)
    {
        var run = await RequireRunAsync(runId);

        run.InputTokens += usage.InputTokens;
        run.OutputTokens += usage.OutputTokens;
        run.CachedInputTokens += usage.CachedInputTokens;
        if (!string.IsNullOrWhiteSpace(providerRequestId))
        {
            run.ProviderRequestId = providerRequestId;
        }

        run.EstimatedCost = await costCalculator.EstimateAsync(
            run.Provider,
            run.Model,
            new AiProviderUsage
            {
                InputTokens = run.InputTokens,
                OutputTokens = run.OutputTokens,
                CachedInputTokens = run.CachedInputTokens,
            },
            run.StartedAt);

        await dbContext.SaveChangesAsync();
    }

    public async Task IncrementToolCallCountAsync(long runId, int count)
    {
        var run = await RequireRunAsync(runId);
        run.ToolCallCount += count;
        await dbContext.SaveChangesAsync();
    }

    public async Task CompleteAsync(long runId, long assistantMessageId)
    {
        var run = await RequireRunAsync(runId);
        run.Status = AiRunStatus.Completed;
        run.AssistantMessageId = assistantMessageId;
        Finish(run);
        await dbContext.SaveChangesAsync();
    }

    public async Task FailAsync(long runId, Exception exception)
    {
        var run = await RequireRunAsync(runId);
        run.Status = AiRunStatus.Failed;
        run.ErrorCode = exception.GetType().Name;
        run.ErrorMessage = redactionService.RedactText(exception.Message);
        Finish(run);
        await dbContext.SaveChangesAsync();
    }

    public async Task MarkLimitExceededAsync(long runId, string errorCode, string errorMessage)
    {
        var run = await RequireRunAsync(runId);
        run.Status = AiRunStatus.LimitExceeded;
        run.ErrorCode = errorCode;
        run.ErrorMessage = redactionService.RedactText(errorMessage);
        Finish(run);
        await dbContext.SaveChangesAsync();
    }

    private static void Finish(AiRun run)
    {
        run.CompletedAt = DateTime.UtcNow;
        run.DurationMilliseconds = (int)Math.Max(0, (run.CompletedAt.Value - run.StartedAt).TotalMilliseconds);
    }

    private async Task<AiRun> RequireRunAsync(long runId) =>
        await dbContext.AiRuns.FirstOrDefaultAsync(r => r.Id == runId)
        ?? throw new KeyNotFoundException("AI run not found.");

```csharp
using FitMate.Core.Settings;
using FitMate.DB.Enums;
using FitMate.Integrations.AI.Models;
using Microsoft.Extensions.Options;

namespace FitMate.Services.AI;

public class AiContextBuilder : IAiContextBuilder
{
    private readonly IAiConversationService conversationService;
    private readonly IAiPromptBuilder promptBuilder;
    private readonly AiOptions options;

    public AiContextBuilder(
        IAiConversationService conversationService,
        IAiPromptBuilder promptBuilder,
        IOptions<AiOptions> options)
    {
        this.conversationService = conversationService;
        this.promptBuilder = promptBuilder;
        this.options = options.Value;
    }

    public async Task<List<AiProviderMessage>> BuildAsync(long conversationId, long userId)
    {
        var history = await conversationService.GetContextMessagesAsync(
            conversationId,
            userId,
            options.MaximumConversationMessages);

        var messages = new List<AiProviderMessage>
        {
            AiProviderMessage.FromSystem(promptBuilder.BuildSystemPrompt()),
        };

        foreach (var message in history)
        {
            switch (message.Role)
            {
                case AiMessageRole.User:
                    messages.Add(AiProviderMessage.FromUser(message.Content));
                    break;
                case AiMessageRole.Assistant:
                    messages.Add(AiProviderMessage.FromAssistant(message.Content));
                    break;
                // ToolCall / ToolResult messages are persisted for auditing but are re-sent only
                // within the run that produced them, so they are not replayed from history.
                default:
                    break;
            }
        }

        return messages;
    }
}

6. 8. Any other exception → `runService.FailAsync`, `usageService.ReleaseAsync`, rethrow. Usage is **never** both committed and released.
9. Exceeding `MaximumToolCallsPerRun` mid-loop behaves like step 7 with code `tool_call_limit`.
10. A tool that fails does **not** abort the run: the failure is returned to the model as a tool result so it can recover (the registry already recorded the failed `AiToolExecution`).

using FitMate.Core.JsonModels.AI;
using FitMate.Core.Settings;

using FitMate.Integrations.AI.Abstractions;

using System.Text.Json;

namespace FitMate.Services.AI;

public class AiOrchestrator : IAiOrchestrator
{
    private readonly IAiConversationService conversationService;
    private readonly IAiRunService runService;
    private readonly IAiContextBuilder contextBuilder;
    private readonly IAiToolRegistry toolRegistry;
    private readonly IAiCompletionProvider completionProvider;
    private readonly IAiModelRouter modelRouter;
    private readonly IAiPromptBuilder promptBuilder;
    private readonly IEntitlementService entitlementService;
    private readonly IUsageService usageService;
    private readonly AiOptions options;

    public AiOrchestrator(
        IAiConversationService conversationService,
        IAiRunService runService,
        IAiContextBuilder contextBuilder,
        IAiToolRegistry toolRegistry,
        IAiCompletionProvider completionProvider,
        IAiModelRouter modelRouter,
        IAiPromptBuilder promptBuilder,
        IEntitlementService entitlementService,
        IUsageService usageService,
        IOptions<AiOptions> options)
    {
        this.conversationService = conversationService;
        this.runService = runService;
        this.contextBuilder = contextBuilder;
        this.toolRegistry = toolRegistry;
        this.completionProvider = completionProvider;
        this.modelRouter = modelRouter;
        this.promptBuilder = promptBuilder;
        this.entitlementService = entitlementService;
        this.usageService = usageService;
        this.options = options.Value;
    }

    public async Task<SendAiMessageResponse> SendAsync(long conversationId, SendAiMessageRequest request, long userId)
    {
        if (string.IsNullOrWhiteSpace(request.Content))
        {
            throw new FitMateException("The message cannot be empty.");
        }

        await entitlementService.RequireFeatureAsync(userId, SubscriptionFeature.AiChat);
        var reservation = await usageService.ReserveAsync(userId, SubscriptionFeature.AiChat, 1);

        // Ownership is enforced here — a foreign conversation throws before the run is created.
        await conversationService.AddUserMessageAsync(conversationId, request.Content, userId);

        var model = modelRouter.ResolveCompletionModel();
        var run = await runService.StartAsync(
            userId,
            conversationId,
            options.Provider,
            model,
            promptBuilder.SystemPromptVersion);

        var usedTools = new List<string>();

        try
        {
            var messages = await contextBuilder.BuildAsync(conversationId, userId);
            var toolContext = new AiToolContext
            {
                UserId = userId,
                ConversationId = conversationId,
                AiRunId = run.Id,
                IsAdmin = false,
            };
            var toolDefinitions = toolRegistry.GetDefinitions(toolContext);
            var providerTools = toolDefinitions.Select(AiToolDefinitionMapper.ToProviderTool).ToList();
            var totalToolCalls = 0;

            using var timeout = new CancellationTokenSource(TimeSpan.FromSeconds(options.TimeoutSeconds));

            for (var iteration = 0; iteration < options.MaximumToolIterations; iteration++)
            {
                var providerResponse = await completionProvider.CompleteAsync(
                    new AiCompletionRequest
                    {
                        Messages = messages,
                        Tools = providerTools,
                        Model = model,
                    },
                    timeout.Token);

                await runService.AddUsageAsync(run.Id, providerResponse.Usage, providerResponse.ProviderRequestId);

                if (providerResponse.ToolCalls.Count == 0)
                {
                    var assistantMessage = await conversationService.AddAssistantMessageAsync(
                        conversationId,
                        providerResponse.Text,
                        userId);

                    await runService.CompleteAsync(run.Id, assistantMessage.Id);
                    await usageService.CommitAsync(reservation.Id);

                    return new SendAiMessageResponse
                    {
                        ConversationId = conversationId,
                        Message = assistantMessage,
                        UsedTools = usedTools,
                        Usage = await BuildUsageAsync(userId),
                    };
                }

                totalToolCalls += providerResponse.ToolCalls.Count;
                if (totalToolCalls > options.MaximumToolCallsPerRun)
                {
                    const string message = "The assistant requested too many tools for a single message.";
                    await runService.MarkLimitExceededAsync(run.Id, "tool_call_limit", message);
                    await usageService.ReleaseAsync(reservation.Id);
                    throw new AiToolLimitExceededException(message);
                }

                await runService.IncrementToolCallCountAsync(run.Id, providerResponse.ToolCalls.Count);

                foreach (var toolCall in providerResponse.ToolCalls)
                {
                    usedTools.Add(toolCall.Name);

                    AiToolExecutionResult result;
                    try
                    {
                        result = await toolRegistry.ExecuteAsync(toolCall, toolContext, timeout.Token);
                    }
                    catch (AiToolNotFoundException notFound)
                    {
                        // The registry already recorded a Rejected execution; hand the failure back
                        // to the model so it can apologise or try a different approach.
                        result = new AiToolExecutionResult
                        {
                            Success = false,
                            ErrorCode = "tool_not_found",
                            ErrorMessage = notFound.Message,
                        };
                    }

                    var resultJson = JsonSerializer.Serialize(result.Success
                        ? result.Data ?? new { success = true }
                        : new { error = result.ErrorCode, message = result.ErrorMessage });

                    await conversationService.AddToolCallMessageAsync(
                        conversationId, userId, toolCall.Name, toolCall.Id, toolCall.ArgumentsJson);
                    await conversationService.AddToolResultMessageAsync(
                        conversationId, userId, toolCall.Name, toolCall.Id, resultJson);

                    messages.Add(AiProviderMessage.FromToolCall(toolCall));
                    messages.Add(AiProviderMessage.FromToolResult(toolCall.Id, resultJson));
                }
            }

            const string iterationMessage = "The assistant could not finish within the allowed number of steps.";
            await runService.MarkLimitExceededAsync(run.Id, "tool_iteration_limit", iterationMessage);
            await usageService.ReleaseAsync(reservation.Id);
            throw new AiToolLimitExceededException(iterationMessage);
        }
        catch (AiToolLimitExceededException)
        {
            throw;   // run already marked and usage already released above
        }
        catch (Exception exception)
        {
            await runService.FailAsync(run.Id, exception);
            await usageService.ReleaseAsync(reservation.Id);
            throw;
        }
    }

    private async Task<AiUsageSummaryModel> BuildUsageAsync(long userId)
    {
        var availability = await entitlementService.GetAvailabilityAsync(userId, SubscriptionFeature.AiChat);
        return new AiUsageSummaryModel
        {
            Feature = nameof(SubscriptionFeature.AiChat),
            Used = availability.Used,
            Limit = availability.Limit,
            Remaining = availability.Remaining,
        };
    }
}

```typescript
import { useCallback, useEffect, useState } from "react";
import { aiService } from "@/services/aiService";
import {
  AiMessageRole,
  type AiConversationModel,
  type AiConversationSummaryModel,
  type AiMessageModel,
  type AiUsageSummaryModel,
} from "@/types";

export function useAiCoach() {
  const [conversations, setConversations] = useState<AiConversationSummaryModel[]>([]);
  const [activeConversation, setActiveConversation] = useState<AiConversationModel | null>(null);
  const [usage, setUsage] = useState<AiUsageSummaryModel | null>(null);
  const [isSending, setIsSending] = useState(false);
  const [activeTools, setActiveTools] = useState<string[]>([]);
  const [error, setError] = useState<string | null>(null);

  const loadConversations = useCallback(async () => {
    const response = await aiService.listConversations();
    if (response.data.success && response.data.data) {
      setConversations(response.data.data);
    }
  }, []);

  const openConversation = useCallback(async (id: number) => {
    const response = await aiService.getConversation(id);
    if (response.data.success && response.data.data) {
      setActiveConversation(response.data.data);
    }
  }, []);

  const startConversation = useCallback(async () => {
    const response = await aiService.createConversation();
    if (response.data.success && response.data.data) {
      setActiveConversation(response.data.data);
      await loadConversations();
    }
  }, [loadConversations]);

  const send = useCallback(
    async (content: string) => {
      if (!activeConversation || !content.trim()) {
        return;
      }

      const optimistic: AiMessageModel = {
        id: -Date.now(),
        role: AiMessageRole.User,
        content,
        toolName: null,
        dateCreated: new Date().toISOString(),
      };
      setActiveConversation({
        ...activeConversation,
        messages: [...activeConversation.messages, optimistic],
      });
      setIsSending(true);
      setActiveTools([]);
      setError(null);

      try {
        const response = await aiService.sendMessage(activeConversation.id, { content });
        const result = response.data;
        if (!result.success || !result.data) {
          setError(result.error ?? "The assistant could not answer.");
          return;
        }

        setActiveTools(result.data.usedTools);
        setUsage(result.data.usage);
        await openConversation(activeConversation.id);
        await loadConversations();
      } catch {
        setError("The assistant is unavailable right now. Please try again.");
      } finally {
        setIsSending(false);
      }
    },
    [activeConversation, loadConversations, openConversation],
  );

  useEffect(() => {
    void loadConversations();
  }, [loadConversations]);

  return {
    conversations,
    activeConversation,
    usage,
    isSending,
    activeTools,
    error,
    openConversation,
    startConversation,
    send,
  };
}
```

- Every run records provider, model, prompt version, token counts, duration, tool executions with per-tool duration, and an estimated cost from `AiModelPricing` (null when no pricing row exists).

- Limits are enforced: max tool iterations, max tool calls per run, request timeout, and the allow-list (unknown or unavailable tools are rejected and recorded, never executed).
- Usage is reserved before the run and either committed exactly once on success or released exactly once on failure — never both.
- **No mutation is possible yet**: no proposal tools are registered and nothing in this plan writes domain entities.
